# ألعاب أثَر

ألعاب ومسابقات ثقافية جماعية من لجنة أثَر، كل لعبة في مجلد خاص بها.

| اللعبة | المجلد | الوصف |
|---|---|---|
| ترابيع | `tarabee/` | جاوب صح واحتل المربعات، والأكثر يفوز |
| من سيربح التيلفون | `telephone/` | أسئلة شفهية بسُلّم نقاط تصاعدي وخزينة ووسائل مساعدة |
| السلم والثعبان | `snakes/` | نرد وسلالم وثعابين بلوحة واقعية وخمسة أشكال وثلاثة توزيعات |
| سهمك الصاعد | `sahm/` | مسابقة أسئلة بسوق أسهم المدن: مكافآت وبيع وشراء وأسعار تتغيّر كل جولة (حظ + منطق) ومفاجآت |
| مسرح جريمة | `crime/` | مسابقة تحقيق: القاتل والمقتول والأداة والمكان والوقت بأدلة تستبعد الاحتمالات، وأسئلة من ديوان أو من المشرف أو بلا أسئلة، ثم تصويت. على شاشة واحدة أو جوال لكل فريق، مع ثلاث أجواء جريمة إضافية |
| جرس أثَر | `buzzer/` | نظام جرس للمسابقات: غرفة برمز وQR، جرس كبير على جوال كل مشارك، أسرع ضغطة بوقت الخادم وبأجزاء الثانية ثم البقية بالترتيب، مع إعادة الضبط والمنع والإخراج |
| ديوان | `diwan/` | بنك أسئلة المسابقات: ١١٨٨ سؤالًا في ١٣ ديوانًا، بهوية ديوان مع التبديل إلى ثيمات أثَر |

## الهيكلة
```
index.html, home.css, home.js   الصفحة الرئيسية
assets/athar.css                الهوية المشتركة: الخط، الثيمات، الشعار
assets/athar-sound.js           الأصوات المشتركة (مؤثرات بلا موسيقى ولا آلات)
assets/sounds/                  مقاطع صوتية مسجّلة (إعلان الفائز)
assets/*.png                    شعارات أثَر (الأساسي والمعكوس)
assets/fonts/                   ملفات خط ثمانية (لا تُرفع بسبب الترخيص)
tarabee/                        لعبة ترابيع
telephone/                      مسابقة من سيربح التيلفون
snakes/                         لعبة السلم والثعبان
buzzer/                         جرس أثَر (index.html شاشة المقدّم، play.html صفحة المشارك، net.js الاتصال عبر Firebase)
diwan/                          بنك أسئلة ديوان (data.js مولّد من ملفات الأسئلة الأصلية)
sahm/                           مسابقة سهمك الصاعد (questions.js بنك الأسئلة)
crime/                          مسابقة مسرح جريمة (team.html صفحة الفريق بالجوال، net.js الاتصال: Firebase إذا وُجدت firebase-config.js وإلا ntfy.sh، الأسئلة من ../diwan/data.js)
assets/athar-firebase.js        إعدادات Firebase المشتركة (مشروع athar-gamesmsr7)
database.rules.json, firebase.json   قواعد Firebase Realtime Database لمسرح جريمة وجرس أثَر (firebase deploy --only database)
```

## قواعد ثابتة لكل الألعاب
- هوية أثَر: خط Thmanyah Sans، وثلاثة ثيمات (فاتح، كحلي، أزرق أثَر) مع مبدّل محفوظ
- عربي واتجاه RTL، ومتجاوب مع الجوال والآيباد والكمبيوتر
- الأصوات مؤثرات صوتية فقط (طبيعة، فم، تصفير، تصفيق…)، بلا موسيقى ولا آلات

## إضافة لعبة جديدة
أنشئ مجلدًا باسم اللعبة فيه `index.html` و`style.css` و`app.js`، واربط `../assets/athar.css` قبل ملف التنسيق، ثم أضف بطاقتها في `index.html` الرئيسي قبل بطاقة «قريبًا». بطاقة ديوان (بنك الأسئلة) تبقى دائمًا الأخيرة في الترتيب.

## الخط
ضع `thmanyahsans-Medium.woff2` و`thmanyahsans-Bold.woff2` في `assets/fonts/` محليًا. بدونها يعمل الخط الاحتياطي IBM Plex Sans Arabic.
